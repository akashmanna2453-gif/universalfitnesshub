# 🏋️ Universal Fitness Hub

A modern, responsive fitness website designed to provide users with an easy way to explore fitness services, discover training options, and connect with the gym.

## 🌐 Live Demo

https://universalfitnesshub.vercel.app/

## 📌 About the Project

Universal Fitness Hub is a responsive fitness website built with a clean and modern interface. The website focuses on presenting fitness services and information in an engaging way while making it simple for visitors to get in touch with the gym.

## ✨ Features

* 📱 Fully responsive design
* 🏋️ Fitness and workout information
* 👨‍🏫 Trainer and service sections
* 📞 Contact and enquiry options
* 💬 WhatsApp integration for direct communication
* 📍 Direct Google Maps location integration
* 🎨 Modern and user-friendly interface
* ⚡ Fast and lightweight frontend

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript**
* **Vercel** — Deployment

## 🎯 Project Highlights

### 💬 WhatsApp Integration

Visitors can directly connect with the gym through WhatsApp, making enquiries and communication easier.

### 📍 Google Maps Integration

The website provides direct access to the gym's location through Google Maps, helping visitors find the location easily.

### 📱 Responsive Design

The interface is designed to work across desktop, tablet, and mobile devices.

## 🚀 Getting Started
